# ⚠️ 安全上の警告

<HaiLocalization languages={['en', 'ja', 'ko', 'zh-Hans', 'zh-Hant']} applicationIsLocalized={true} />

通常、家庭用のロボットアームは、滑らかな曲線を生成する数学的アルゴリズムによって制御されています。
そのため動きは非常に予測しやすく、テストもしやすく、ロボットアームの動作が快適で、不規則な動きが比較的少ないことが保証されています。

しかし、**このソフトウェアではそうではありません**。数学的アルゴリズムの代わりに、ロボットアームは共有された仮想空間によって制御されます。
これは不完全なシステムです。

共有された仮想空間を通じてポジションシステムを使用する場合、**ロボットアームの動作はこうした安全性の恩恵を受けられません**。
以下のリスクを十分に考慮してください：
- ロボットアームの位置を操作している存在や人物のトラッキングが失われた場合、ロボットアームはそのトラッキングの喪失を目標位置として扱う可能性があります。
- ロボットアームの位置を操作している存在や人物の動きが速すぎる場合、ロボットアームはモーターの能力を超える速さでその位置に到達しようとする可能性があります：
  その場合、一部のモーターが他のモーターよりもはるかに早く最終位置に到達します。
  その結果、移動中にロボットアームが予期しない角度になります。デバイスの自由度が多いほど、この現象は起こりやすくなります。
- さらに、ファームウェアとハードウェアは、従来のソフトウェアでは通常とは見なされない位置にさらされるため、それらの位置は十分にテストされていない可能性があります。
  こうした通常とは異なる位置によって、ロボットアームが損傷したり、ロボットアームの想定位置を損なうファームウェアのバグが表面化したりする可能性があります。

共有された仮想環境でロボットアームを使用する場合は、責任を持って行動し、**すべての参加者にとってより安全な体験となるよう、十分にコミュニケーションを取ってください**。

**ご自身の身の安全については、すべてご自身の責任となります。**

## ⚠️ 火災の危険

低品質なサーボの中には、焼損して短絡したままになるものがあり、ロボットアームの一部が一部の3Dプリント材料のガラス転移温度を超えるほど
発熱することがあります。これは火災の危険につながる可能性があります。

デバイスから目を離さず、**使用しないときは電源を切ってください**。デバイスの電源が入ったまま眠らないでください。

:::danger
ロボットアームを自作する場合は、**安価な20kg/cmの粗悪な赤いサーボは絶対に購入しないでください**。焼損することで悪名高い製品です。
