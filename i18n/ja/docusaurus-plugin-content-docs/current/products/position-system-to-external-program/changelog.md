## 0.1.0-beta.6

🌕 *Unityのシェーダーが変更されました。一部の機能を利用するには、最新バージョンを使ってアバターを再アップロードしてください。*

### 新機能：最大の高さのハードリミットオプションを追加 {/* #new-feature-add-a-maximum-height-hard-limit-option */}

ハードリミットは、ロボットアームが移動を許可される最大の高さを下げます。

この値を変更すると、仮想スケールが内部で補正され、ハードリミット間の範囲を移動するのに、引き続き仮想空間での全移動距離が
必要になるようにします。これは Compensate virtual scale チェックボックスで無効にできます。

### 新機能：オフセットのピッチオプションを追加 {/* #new-feature-add-an-offset-pitch-option */}

オフセットでは、位置が適用された後のロボットアームのピッチ角を調整できます。

これは移動の方向を変えるものではありません。仮想空間での移動は、物理空間でも同じ方向の移動になります。

### 新機能：ロボットアーム全体を回転させる設定を追加 {/* #new-feature-add-a-setting-to-rotate-the-robotic-arm-entirely */}

Rotate machine 設定を使用すると、仮想空間でのある方向への移動が、物理空間では別の方向への移動になります。

- これにより、仮想空間での水平方向の動きを、物理空間での垂直方向の動きに変えることができます。
- また、水平向きに設置されたロボットアームを使用している場合は、この設定で空間を補正し、仮想空間と物理空間を一致させることができます。

### VRCFuryのプレハブを追加 {/* #add-vrcfury-prefab */}

VRCFuryのインストール手順は[こちらに記載されています](./platform-setup#vrchat-avatars-sdk-using-vrcfury)。

### その他 {/* #other-2 */}

修正：
- 非表示のウィンドウを無視するようになったため、ウィンドウ名の検索が速くなりました。
- エンコーダーメッシュに、削除済みのAnimationコンポーネントが付かなくなりました（メッシュアセットのリグの「Animation Type」が None に設定されました）。

その他：
- **ルートのPIDコントローラーが不安定なため、このリリースでは無効にしました。**
- プレハブのインストールにlilToonを必要としないよう、ギズモのキャリブレーターモデルのマテリアルをlilToonからStandardに切り替えました。
- ブルームをそれほど考慮する必要がなくなったため、赤いピクセルではなく灰色のピクセルに戻しました。これを反映して、シェーダーのバージョンを V1.0.1 に変更しました。
- WebSocketはResonite以外でも使用できるため、Resonite WebSockets という表記をすべて単に WebSockets に変更しました。
- Debug メニューで、仮想と物理のスケールの差の推定値を表示するようにしました。これは将来の作業に向けたもので、
  仮想空間を移動した結果としてカメラが動き始めたときに、プレイスペース内のオブジェクトを再配置するための準備です。

## 0.1.0-beta.3

🌃 *Unityのプレハブとシェーダーに変更はありません。*

### 新機能：Resonite対応のためのオプションのWebSocketサービスを追加 {/* #new-feature-add-optional-websocket-service-for-resonite-support */}

*Resonite* からWebSocketに位置と法線を送信することで、ロボットアームを操作できるようになりました。
送信される位置は実質的に同じDPS系ライトをシミュレートするため、ロボットアームの動作には引き続き Robotics タブの設定が適用されます。

有効なメッセージを受信すると、データ抽出のロジックはすべて上書きされ、それ以降の画像処理やデータ処理は行われません。

詳しくは、[README.md の *Websockets as an alternative input system* セクション](https://github.com/hai-vr/position-system-to-external-program?tab=readme-ov-file#websockets-as-an-alternative-input-system)をご覧ください。

## 0.1.0-beta.1

### 新機能：標準的なDPS系ライトの位置をロボットアームに接続 {/* #new-feature-connect-the-position-of-standard-dps-like-lights-to-a-robotic-arm */}

これは最初のベータ版です。

このベータ版には、次のことができる実行ファイル（`.exe`）が含まれています：
- OpenVRのテクスチャを通じて送信されたDPS系のデータをデコードする。
- ウィンドウを通じて送信されたDPS系のデータをデコードする。
- Tcodeプロトコル（SR6とOSR2で使用）を使うロボットアームが接続された任意のシリアルポートに、DPS系のデータを送信する。

パッケージには、プレハブとシェーダーが含まれています：
- プレハブはModular Avatarを使用し、メニューを作成します。同期パラメーターのコストは合計2ビットです。
- プレハブに手動の設定は必要ありません。シェーダーはプレハブ内ですでに設定されています。
