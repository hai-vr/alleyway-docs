# ⚠️ 安全警告

<HaiLocalization languages={['en', 'ja', 'ko', 'zh-Hans', 'zh-Hant']} applicationIsLocalized={true} />

一般而言，家用機械手臂傳統上是由產生平滑曲線的數學演算法來控制。
這使它們的運動非常容易預測、便於測試，並能確保機械手臂的動作舒適，且相對不會出現雜亂無章的動作。

然而，**本軟體並非如此**。機械手臂不是由數學演算法控制，而是由一個共享的虛擬空間控制，
而這是一個不完善的系統。

透過共享虛擬空間使用位置系統時，**機械手臂的運動將無法獲得這些安全保障**。
請仔細考慮以下風險：
- 如果控制你的機械手臂位置的實體或人員發生追蹤遺失，機械手臂可能會將這種追蹤遺失當作一個要到達的位置。
- 如果控制你的機械手臂位置的實體或人員移動過快，機械手臂可能會嘗試以超出馬達能力的速度到達該位置：
  在這種情況下，部分馬達會比其他馬達早得多到達最終位置。
  這會導致機械手臂在移動過程中出現意料之外的角度。你的裝置自由度越多，就越容易發生這種情況。
- 此外，韌體和硬體將會處於傳統軟體可能認為不尋常的位置，因此這些位置可能較少經過測試。
  這些不尋常的位置可能會損壞你的機械手臂，或暴露出可能影響機械手臂預期位置的韌體錯誤。

如果你選擇在共享虛擬環境中使用機械手臂，請負起責任，並**充分溝通，以確保各方都能獲得更安全的體驗**。

**你需對自己的人身安全承擔全部責任。**

## ⚠️ 火災危險

一些劣質伺服馬達可能會燒毀並發生短路，導致機械手臂的部分零件發熱，溫度甚至可能超過
某些 3D 列印材料的玻璃轉移溫度。這可能會造成火災危險。

請留意你的裝置，並**在不使用時關閉電源**。不要在裝置仍通電時入睡。

:::danger
如果你打算自己製作機械手臂，**不要購買任何廉價的 20kg/cm 劣質紅色伺服馬達**。它們以容易燒毀而惡名昭彰。
